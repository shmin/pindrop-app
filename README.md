# Google Sheets 사진 직접 등록 웹앱

사진을 Google Drive에 별도 저장하지 않고, Google 스프레드시트의 사진 열 위치에 직접 삽입하는 Apps Script 웹앱입니다.

## 시트 준비

첫 번째 행에 열 이름을 만드세요.

```text
등록일 | 품목명 | 분류 | 수량 | 사진1 | 사진2 | 사진3 | 메모
```

- `사진1`, `사진2`, `사진3`처럼 사진 열이 여러 개면 열 개수가 최대 사진 수가 됩니다.
- 사진 열이 하나라면 `현장사진(최대 5장)`처럼 적을 수 있습니다. 이 경우 사진은 같은 셀을 기준으로 세로로 배치됩니다.
- 두 번째 행에 Google Sheets 드롭다운을 설정하면 웹앱도 같은 선택 항목을 표시합니다.
- 열 이름에 `*` 또는 `필수`가 있으면 필수 입력칸으로 처리됩니다.

## 운영자 최초 설치 — 한 번만 진행

이 과정은 앱 운영자만 진행합니다. 최종 사용자는 설치할 필요가 없습니다.

1. 운영자가 [script.google.com](https://script.google.com/)에서 `새 프로젝트`를 만듭니다. 특정 시트 안에서 만들 필요가 없습니다.
2. 기본 `Code.gs` 내용을 이 폴더의 `Code.gs` 내용으로 교체합니다.
3. `+ → HTML`을 눌러 파일 이름을 `Index`로 만들고 `Index.html` 내용을 붙여넣습니다.
4. 프로젝트 설정에서 `appsscript.json 매니페스트 파일 표시`를 켜고 이 폴더의 `appsscript.json` 내용으로 교체합니다.
5. `배포 → 새 배포 → 웹 앱`을 선택합니다.
6. `다음 사용자로 실행`은 `웹 앱에 액세스하는 사용자`를 선택합니다.
7. 조직 내부 앱이면 조직 사용자, 외부 사용자도 쓸 앱이면 허용 가능한 액세스 범위를 선택해 배포합니다.
8. 생성된 웹 앱 주소 하나만 사용자에게 전달합니다.

## 최종 사용자의 사용 방법

1. 전달받은 웹앱 주소를 엽니다.
2. 처음 사용할 때만 자신의 Google 계정으로 Sheets 접근 권한을 승인합니다.
3. 자신이 편집 권한을 가진 스프레드시트 주소를 붙여넣습니다.
4. 탭을 고르고 사진과 내용을 등록합니다.

사용자는 Apps Script를 만들거나 코드를 복사하지 않습니다. 웹앱이 사용자 권한으로 그 사용자의 시트를 읽고 사진을 삽입합니다.

## 작동 방식

1. 사용자가 스프레드시트 주소를 입력합니다.
2. 서버가 첫 행의 열 이름, 두 번째 행의 드롭다운과 표시 형식을 읽습니다.
3. 웹앱이 날짜·숫자·드롭다운·메모·사진 입력칸을 자동 생성합니다.
4. 휴대폰 사진을 긴 변 1,200px, JPEG 품질 약 80%로 압축합니다.
5. Apps Script가 다음 빈 행을 만들고 텍스트를 기록합니다.
6. 사진을 Blob으로 변환해 `Sheet.insertImage(blob, column, row)`로 셀 위치에 고정합니다.
7. 사진 크기는 96×96px로, 행 높이와 사진 열 너비도 자동 조절합니다.

## 중요한 제한

- Apps Script의 Blob 이미지 삽입 한도 때문에 압축된 사진 한 장은 2MB 이하여야 합니다.
- 사진은 셀 값이 아니라 해당 셀을 기준점으로 삼는 이미지 객체입니다.
- 사진이 많은 시트는 점점 무거워질 수 있습니다.
- 정렬과 필터를 자주 사용하는 표라면 사진마다 별도의 열을 두는 방식을 권장합니다.
